# Bầu cử giữa kỳ Mỹ 2026: bảng kết quả

Trang: https://hainguyenee.github.io/bau-cu-2026/

Bảng số ghế Hạ viện, Thượng viện, các cuộc đua Thượng viện và thống đốc, tổng hợp từ dự báo (projection) của các hãng tin Mỹ. Chưa phải kết quả chính thức.

Dữ liệu nằm trong `data/races.json` và `data/seats.json`, được cập nhật tự động khoảng mỗi 2 giờ.
